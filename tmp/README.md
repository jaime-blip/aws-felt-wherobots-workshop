# tmp/ — Development Utility Scripts

These are **one-time extraction scripts** used during workshop development to pull raster data from Wherobots and upload to Felt. They are NOT part of the workshop.

| Script | Purpose |
|--------|---------|
| `extract_flood.py` | Extract MODIS flood rasters for San Diego bbox via Wherobots MCP |
| `extract_opera_flood.py` | Extract OPERA flood dataset |
| `extract_rasters.py` | Generic raster extraction |
| `extract_and_upload_flood.py` | Extract flood rasters + upload to Felt |
| `upload_to_felt.py` | Upload raster files to Felt as layers |
| `query_flood_california.py` | Query California flood data from Wherobots |
