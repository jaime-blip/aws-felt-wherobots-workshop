# Building a Geospatial Agentic AI Stack on AWS

**Turn raw geospatial data into intelligence. Powered by Amazon Aurora PostgreSQL (APG) with PostGIS, Wherobots, and Felt.**

Location data is everywhere. But turning raw geospatial signals into actionable intelligence requires more than a query and a pin on a map.

Whether you're triaging insurance exposure after a catastrophe, determining risk to critical infrastructure, or quantifying weather-driven operational disruptions for an investment thesis, the underlying challenge is the same: turning satellite imagery (floods, fires, temperature) and vector geometries (buildings, parcels, critical infrastructure, road network) data into insights is a problem that spans ingestion, spatial processing, analytics and visualization — and until now, required stitching it all together in fragile, hand-rolled pipelines that don't scale.

In this workshop, you'll dive into the developer experience of creating a geospatial data pipeline with Wherobots MCP and build a geospatial AI agent that generates Felt map apps when prompted using services like APG with PostGIS, Kiro IDE, Strands Agents and Amazon Bedrock.

The result: an end-to-end solution that can take questions in natural language and build interactive map dashboards using satellite imagery, building parcels and a weighted risk scoring methodology applicable across financial institutions, insurers, energy and agricultural organizations.
